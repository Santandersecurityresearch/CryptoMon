Dashboard unavailable

The statistics aggregations are not installed on this deployment.

This page reads its numbers from fapi/app/stats.py, which this service could not import. Nothing is broken and nothing has crashed — the module is not there.

The rest of the service is unaffected. The API under /data and the capture analyser under /analyse do not depend on it.

What still works

Analyse a capture in the browser, or from a terminal, with no server at all: 

python -m pcapscan capture.pcap
python -m pcapscan capture.pcap -f cbom > cbom.json
